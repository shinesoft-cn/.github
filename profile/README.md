## 👋 我们是谁

我们是广州适尔软件（Guangzhou ShineSoft），专注于打造 **韵词字幕**——
一款覆盖 **语音转字幕 → 翻译 → 精修 → 卡拉OK 特效 → 导出成片** 完整流程的
AI 字幕制作软件，让专业剪辑师和普通用户都能轻松上手。

- 🎙️ AI 转录、时间轴自动对齐、19+ 语言联网翻译
- 🎬 多轨道字幕 + 音频波形图联动、CPS 机制、毫秒级精度调节
- 🎤 50+ 卡拉OK 动态特效预设，K-Cut 智能音节切割
- 📤 支持 MP4/MKV/MOV 以及 SRT/ASS/WebVTT/Word/Excel 等 10+ 种格式导出
